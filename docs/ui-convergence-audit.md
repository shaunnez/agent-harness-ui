## Sources and method

The audit used `docs/workflow-product-contract.md`, `design/reference-grill-approved.png`, the approved workflow captures in `output/playwright/workflow-refinement/`, and the candidate-lifecycle reference set in `output/design-qa/candidate-lifecycle/`. The real loopback companion on `127.0.0.1:4310` remained the data source; the Vite client was exercised in the user's in-app browser at `127.0.0.1:4173`.

The baseline pass captured the Command Centre; every historical stage of completed task `AH-015`; completed Grill history on `AH-012`; and the repair-required Implement state on `AH-007`. The convergence pass then exercised stage navigation, exact candidate diff, Test list/detail/back, artifact open/close, Run activity filters, responsive layouts, empty/loading/disconnected fixtures, and a clean console reload. No workflow record or candidate worktree was mutated for visual QA.

## Outcome

The real runtime now uses one typed Evidence Gate presentation layer across all ten stages. Markdown remains the durable artifact, while candidate, package, Test, approval, and activity data are presented through shared primitives. Unsupported controls or data are disabled or labelled unavailable; no API, task-state, candidate, worktree, or merge semantics were invented.

Baseline captures are in `output/ui-convergence-audit/current/`. Final browser evidence and same-input comparisons are in `output/ui-convergence-qa/` and `output/ui-convergence-qa/comparisons/`. The final P0–P3 assessment is appended to `design-qa.md`.
