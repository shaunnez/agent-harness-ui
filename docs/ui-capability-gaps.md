## Scope decision

No backend change was required for this convergence pass. Existing APIs already cover exact candidate diffs, worktree inventory, structured focused-test rows, candidate revisions, work packages, approvals, decisions, artifacts, and real stage mutations. The highest-value future contracts are typed review/scout/specification evidence, explicit gate freshness, package/run telemetry, safe browser QA fixtures, and Pause/Request changes actions.
